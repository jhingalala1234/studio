# **App Name**: CloudX Central

## Core Features:

- User Authentication: Secure access using demo email/password. To begin with demo@demo.com/demodemo, expand later to full email-based authentication.
- Role-Based Access Control: Differentiate permissions based on user level: Presidium, Chair of Directors, Leads.
- Task Assignment: Assign tasks to users with specific roles. Presidium can assign to anyone, others have limited scope.
- Log Viewer: Display a history of assigned tasks and updates, with view tailored to user roles.
- AI Task Prioritization Tool: The application provides LLM powered tool, which is a assistant to the administrator who assigns the work for efficient task Prioritization.
- Dashboard UI: Centralized view of tasks, assignments, and logs for each role.
- Notifications: Provide key notifications to team members

## Style Guidelines:

- Dark background (#000000) for a modern, professional feel.
- Primary color: Vibrant pink (#FB1587) to bring energy.
- Accent color: Electric blue (#2E2BF5) to highlight important interactive elements and call to actions.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines and 'Inter' (sans-serif) for body text. 
- Minimalist icons to represent different tasks and categories.
- Clear visual hierarchy for each role, highlighting assigned tasks and relevant logs.
- Subtle transitions and animations to provide a smooth user experience.
